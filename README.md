# Jogo_2D
jogo para podermos treinar versionamento de código.
2026:
25/08 - Nessa aula aprendemos como funicona o Git e o GitHub, como configurar o codigo antes de começar, dar commits, pushs, a influencia do Git na Unity; Usado de exemplo: um triangulo que ira representar o player no jogo de platarforma 2D, e um square que sera o chao para o player.

27/08- Na aula de hoje aprendemos sobre "Game Design" e como eles são utilizados na hora da criação de jogo, usando de exemplo um jogo chamado,"HOB" que mostra um exemplo de jogo que nao faz uso de dialogos nem caixas e texto, mas mesmo assim consegue passar as informações que o jogador precisa, fazendo uso do proprio ambiente a sua volta, e fazendo tudo muito bem pensado para conseguir transmitir a informação ao jogador; Também começamos a preencher um formulario com as ideias, mecanicas, histori, nome, etc; sobre um jogo individual que deveremos fazer.

17/09- Nessa aula continuamos com a criação do jogo 2D, onde adicionamos os movimentos basicos ao jogador como andar e pular, aprendemos como programarmos essas mecanicas e algumas funções como ForceMode e Vector; Tambem pelo menos pra mim, dei uma pesquisada em movemento para os inimigos na youtube, mas ainda nao testei na pratica pra ver se funciona;
